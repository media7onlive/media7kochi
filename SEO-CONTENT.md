# TECHNICAL SEO RECOMMENDATIONS

---

## 1. Core Web Vitals

- **LCP (Largest Contentful Paint):** Target under 2.5s. Optimize hero images by converting to WebP/AVIF, implement lazy loading for below-fold images, and preload the hero image with `fetchpriority="high"`.
- **FID (First Input Delay):** Target under 100ms. Minimize long tasks, split JavaScript bundles with code splitting, and defer non-critical scripts.
- **CLS (Cumulative Layout Shift):** Target under 0.1. Set explicit width/height on all images and iframes using `aspect-ratio` CSS or wrapper containers (already handled via `LazyImage` component).

## 2. Image Optimization

- Convert all images to **WebP** format (already in use) — good.
- Implement **next-gen format** AVIF for browsers that support it.
- Add `srcset` and `sizes` attributes for responsive images.
- Use descriptive, keyword-rich **ALT text** on every image (provided above).
- Compress all images to under 100KB where possible (tinyPNG, squoosh).
- Lazy load all images below the fold using `loading="lazy"` (already done via `LazyImage`).
- Preload critical images (hero, logo) with `<link rel="preload">`.

## 3. Internal Linking

- Every service page should link to related services (e.g., branding → web design, SEO → content marketing).
- Blog posts should link to relevant service pages and category archives.
- Use descriptive anchor text (not "click here").
- Add breadcrumbs on every page for navigation and schema.
- Link from homepage to key inner pages: About, Services, Portfolio, Blog, Contact.

## 4. External Linking

- Link to high-authority sources where relevant (Google, industry publications).
- Set `rel="noopener noreferrer"` on all external links (already done).
- Link to social profiles in footer.
- Link to Media7 News Portal (`media7news.com`) from homepage.

## 5. Canonical URLs

- Every page must include `<link rel="canonical" href="https://media7cok.com/page-url/" />`.
- Prevent duplicate content issues by setting canonicals on paginated blog pages.
- No `?` parameters should generate unique content without a canonical.

## 6. Sitemap

- Generate `sitemap.xml` including all pages: `/`, `/about`, `/services`, `/services/branding`, `/services/digital-marketing`, `/services/seo`, `/services/social-media-marketing`, `/services/website-development`, `/services/video-production`, `/services/advertising`, `/services/media-planning`, `/services/event-management`, `/services/content-marketing`, `/portfolio`, `/blog`, each blog post, `/contact`, `/careers`, `/privacy`, `/terms`.
- Set `<lastmod>`, `<changefreq>`, and `<priority>` for each.
- Submit sitemap to Google Search Console and Bing Webmaster Tools.

## 7. Robots.txt

```
User-agent: *
Allow: /
Disallow: /admin/
Disallow: /api/

Sitemap: https://media7cok.com/sitemap.xml
```

## 8. PageSpeed Optimization

- Minify CSS, JS, and HTML (Vite already handles this in production builds).
- Enable Gzip/Brotli compression on Vercel (configure in `vercel.json`).
- Reduce render-blocking resources — inline critical CSS, defer non-critical JS.
- Use `font-display: swap` for Google Fonts (already set).
- Remove unused CSS (Tailwind + purgeCSS is configured — verify).
- Use CDN for static assets (Vercel Edge Network).

## 9. Mobile-First Optimization

- Ensure all pages pass Google's Mobile-Friendly test (responsive design already implemented).
- Touch targets minimum 48x48px.
- Font sizes no smaller than 16px to prevent zoom.
- No horizontal scrolling on mobile (test all breakpoints).
- Optimize hero animation frame count for mobile (240 frames → consider reducing to 60 for mobile).

## 10. Accessibility (a11y)

- Add `lang="en"` to `<html>` tag (check `index.html`).
- Ensure proper heading hierarchy (H1 → H2 → H3, no skipping).
- Add `aria-label` to navigation and interactive elements.
- Ensure color contrast ratios meet WCAG AA standards (gold `#F5C542` on black passes — good).
- Add `alt` text to all images (partially done — audit all images).
- Add `aria-expanded` and `aria-controls` to mobile menu toggle.
- Form inputs need associated `<label>` elements (partially done — audit).
- Add skip-to-content link for keyboard users.

## 11. Structured Data (already outlined above)

- **Organization** schema on all pages.
- **LocalBusiness** schema on Homepage and Contact.
- **Service** schema on each service page.
- **FAQPage** schema on homepage FAQ section.
- **BreadcrumbList** schema on all inner pages.
- **WebSite** schema (with SearchAction) on homepage.
- **Article** schema on blog posts.
- Test all structured data with Google's Rich Results Test.

- **Favicon:** Ensure `favicon.ico`, `favicon.svg`, and Apple touch icon exist (partially done).
